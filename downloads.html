Windows Installation Instructions

Requires Windows 10 or Windows 11 (64-bit).

Recommended: NSIS Installer (_x64-setup.exe)

  1. Download the ..._x64-setup.exe installer above and run it.
  2. The installer automatically configures Microsoft Edge WebView2 if it is not already installed.
  3. It registers the nxm:// and emperor:// protocol handlers so “Download with manager” buttons on Nexus Mods open straight in Emperor.
  4. Launch Emperor Mod Manager from the Start Menu and complete the initial setup (see the Wiki Setup Guide).

Alternative: MSI Package or Standalone Binary

  • MSI (.msi): Standard Windows Installer package suitable for managed or scripted deployments.
  • Standalone (emperor-mod-manager.exe): Portable executable if you prefer not to run an installer (note: protocol handlers are not registered automatically).

Linux Installation Instructions

Arch Linux (CachyOS, EndeavourOS, Manjaro)

Install via the official script, which builds a pacman package so the app appears in your desktop menu and nxm:// links work immediately (requires base-devel): 

curl -fsSL https://raw.githubusercontent.com/Emperor-of-Modkind/emperor-mod-manager/main/scripts/install-arch.sh | bash

Or build manually from the release PKGBUILD:

mkdir -p "$HOME/.cache/emperor-mod-manager" && cd "$HOME/.cache/emperor-mod-manager"
curl -fsSL -o PKGBUILD https://github.com/Emperor-of-Modkind/emperor-mod-manager/releases/latest/download/PKGBUILD
makepkg -si

After installing, use Settings → Check for updates in-app to build and install future releases. Uninstall anytime with sudo pacman -R emperor-mod-manager-bin.

Debian / Ubuntu / Pop!_OS / Mint (.deb)

sudo apt install ./Emperor.Mod.Manager_*_amd64.deb

AppImage (Universal)

chmod +x Emperor.Mod.Manager_*_amd64.AppImage
./Emperor.Mod.Manager_*_amd64.AppImage

In-app updates automatically replace the AppImage in place, update .deb installs via apt, or update user-writable binaries from the release tarball.
