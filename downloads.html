Installing on Windows

Requires Windows 10 or Windows 11 (64-bit).

Recommended: NSIS Installer (_x64-setup.exe)

  1. Download and run the ..._x64-setup.exe installer above.
  2. If Microsoft Edge WebView2 isn’t installed yet, the installer will set it up for you.
  3. It also registers nxm:// and emperor:// links so “Download with manager” buttons on Nexus Mods open in Emperor.
  4. Open Emperor Mod Manager from the Start Menu and run through the first-time setup (see the Wiki Setup Guide).

Other Windows Options

  • MSI (.msi): Standard Windows Installer package if you prefer MSI or scripted installs.
  • Standalone (emperor-mod-manager.exe): Portable binary with no installer. Note that nxm:// and emperor:// links won’t be registered automatically.

Installing on Linux

Arch Linux (CachyOS, EndeavourOS, Manjaro)

Run the install script to build and install a pacman package. This adds Emperor to your app menu and sets up nxm:// links right away (needs base-devel): 

curl -fsSL https://raw.githubusercontent.com/Emperor-of-Modkind/emperor-mod-manager/main/scripts/install-arch.sh | bash

Or build it yourself from the release PKGBUILD:

mkdir -p "$HOME/.cache/emperor-mod-manager" && cd "$HOME/.cache/emperor-mod-manager"
curl -fsSL -o PKGBUILD https://github.com/Emperor-of-Modkind/emperor-mod-manager/releases/latest/download/PKGBUILD
makepkg -si

Once installed, you can update from Settings → Check for updates inside the app. To remove it later, run sudo pacman -R emperor-mod-manager-bin.

Debian / Ubuntu / Pop!_OS / Mint (.deb)

sudo apt install ./Emperor.Mod.Manager_*_amd64.deb

AppImage (Universal)

chmod +x Emperor.Mod.Manager_*_amd64.AppImage
./Emperor.Mod.Manager_*_amd64.AppImage

In-app updates replace the AppImage in place, update .deb installs through apt, or swap out user-writable binaries from the release tarball.
