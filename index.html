Supported Sources

Search everything together or filter by site

  • Nexus Mods Premium API & free Download Assist
  • Thunderstore Modpacks, r2modman/Gale codes & dependencies
  • mod.io Browse, download & soft dependency sync
  • P2P Friends Share and sync modlists directly

What it does

Supports Unity/BepInEx, Unreal, RE Engine, FromSoftware, Creation Engine, and id Tech games, keeping staged mods separate from your game folder.

Open the Wiki
Browse

Every source in one list

Search Nexus Mods, Thunderstore, and mod.io together, or filter down to a single site when you know where a mod lives.

Collections & Modpacks

Install whole modlists at once

Grab Nexus Collections, Thunderstore Modpacks, or paste an r2modman/Gale profile code. Dependencies are resolved and version-pinned automatically.

Deployment

Load order & hardlinks

Drag and drop to set load priority. Deployment uses hardlinks when your staging folder and game are on the same drive, and falls back to copying across drives.

Free & Premium Nexus

Built-in Download Assist

Premium accounts get one-click API downloads. On a free account, use the built-in Download Assist (with optional autoclick), nxm:// links, or local archive imports.

Friends & P2P

Sync modlists for co-op

Add friends with a P2P join code, pick who can see each collection (All friends, Specific friends, or Private), and sync the same modlist before you play.

Deep Links

Browser & direct mod links

“Download with manager” (nxm://) links open straight in Emperor. You can also copy an emperor://mod/... URL to send someone directly to a specific mod.

Get Emperor Mod Manager

Grab the latest build for Windows or Linux, and check the Wiki if you need help setting up API keys or game folders.
