Unified Browse

All catalogs in one list

Browse Nexus Mods, Thunderstore, and mod.io together in a single interface, or filter by source whenever you need a specific ecosystem.

Collections & Modpacks

Batch install with ease

Install Nexus Collections, Thunderstore Modpacks, or paste an r2modman/Gale profile code. Soft dependency resolution keeps versions pinned cleanly.

Clean Deployment

Load order & hardlinks

Drag-and-drop load order with instant hardlink deployment on the same drive and automatic copy fallback across separate disks.

Free & Premium Nexus

Download Assist built in

Nexus Premium users get one-click API downloads. Free accounts use in-app Download Assist with optional autoclick, nxm:// staging, and local archive import.

Social & P2P

Share collections with friends

Connect with friends using a P2P join code, control collection privacy (All friends, Specific friends, or Private), and sync modlists together for co-op sessions.

Deep Links

Browser & shareable URLs

“Download with manager” (nxm://) links open right in Emperor, and copyable emperor://mod/... URLs let you send exact mods to anyone.
