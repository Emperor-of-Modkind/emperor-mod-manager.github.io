1. Getting Started & Setup

Emperor Mod Manager works on Linux and Windows 10+. Grab the latest build from the Downloads page, then link your accounts and let it find your games.

Connecting your Nexus Mods API Key

  1. Sign in to Nexus Mods and go to Nexus API Access .
  2. Generate or copy your personal API key.
  3. Open Setup in Emperor and paste it in.
Where your key is stored: Emperor saves your API key in your OS keyring when available. Otherwise, it falls back to the app config folder (restricted to mode 0600 on Linux).

Connecting mod.io (Optional)

  1. Go to mod.io Access and generate or copy an API key.
  2. Paste it under Setup → mod.io in the app.
  3. In Library → Catalog & deploy settings, check or enter the game’s mod.io game ID (many games already have one filled in).

Finding & Managing Games

Emperor scans the usual game launchers automatically:

  • Linux: Steam, Heroic, Lutris, and Bottles.
  • Windows: Steam, Epic Games Launcher, and Heroic (if installed).

Click any detected game in your Library to check its deploy settings and start browsing mods from Nexus, Thunderstore, and mod.io.

2. Free-Account Downloads & Download Assist

Nexus Premium accounts get one-click API downloads and automatic batch installs for collections. On a free Nexus account, you can use the built-in Download Assist:

  1. Open a mod file and click Download Assist.
  2. The first time, sign in to Nexus Mods inside the assist window and check Stay signed in so you don’t have to log in again.
  3. With autoclick turned on (enabled by default in Settings), Download Assist waits for the button to appear and clicks Mod Manager Download or Slow Download for you.
  4. You can also click “Download with manager” (nxm://) links in your browser, or use Import mod… on the Mods tab to add a local .zip, .7z, .rar, single mod file, or extracted folder.
Session expired? If Nexus logs you out or you want to switch accounts, use Settings → Clear Nexus website session and sign in again.

3. Managing Mods & Collections

Group mods into collections, tweak your load order, or import modpacks shared by the community.

Installing Collections & Modpacks

  • Nexus Collections: Browse and install Nexus Collections inside the app. Premium accounts download everything in one go; free accounts step through each mod with Download Assist (hit Cancel on the status banner anytime to stop).
  • Thunderstore Modpacks & Profile Codes: Install Thunderstore Modpacks directly, or paste an r2modman / Gale profile code to pull in a full modlist with soft dependency resolution and pinned versions.

Load Order & Deploying

  1. Open a game’s Mods tab to toggle mods on or off and change their order.
  2. Drag and drop mods to set priority. Mods lower in the list overwrite files from earlier ones.
  3. Hit Deploy to apply your changes. Emperor uses hardlinks when the staging folder and game folder are on the same drive, and falls back to copying files if they’re on different drives.

Shareable Mod Links

Click Copy link on any mod page to get an emperor://mod/... URL. Anyone with Emperor installed can open it to jump straight to that mod (works for Nexus, Thunderstore, and mod.io).

4. Adding Friends & P2P Collection Sharing

Emperor has a peer-to-peer (P2P) Friends system for sharing and syncing modlists with your co-op group, with no account server required.

Setting Up Your Profile

  1. Open Settings → Social.
  2. Set your Display name and click Save.
  3. Optionally click Choose Picture to pick an avatar (PNG, JPEG, WebP, or GIF; it gets resized automatically and shared with connected friends).

Adding a Friend

  1. Open the Friends page in the sidebar.
  2. To invite someone, click Share Friend Code to copy your P2P join code and send it over.
  3. To add someone, click Add Friend, paste their code, and hit Connect. Emperor connects directly over P2P.

Collection Privacy

Open the Sharing dialog on any collection to pick who can see and sync it:

  • All friends: Any connected friend can see and sync it.
  • Specific friends: Choose individual friends (with Select all / Clear buttons) who get access.
  • Private: Only visible to you.

Syncing a Friend’s Collection

Click a connected friend on the Friends page to see the collections they’ve shared, grouped by game. Open one to check what’s inside, pick the target game, and click Sync or Install to match their setup.

5. Data Locations & Mod Recovery

Config files, staged mods, and download caches live in your OS’s standard app folders:

Purpose Linux Windows
Config ~/.config/emperor-mod-manager/ %APPDATA%\emperormodmanager\emperor-mod-manager\
Staged mods & load order ~/.local/share/emperor-mod-manager/ %APPDATA%\emperormodmanager\emperor-mod-manager\
Download cache ~/.cache/emperor-mod-manager/ %LOCALAPPDATA%\emperormodmanager\emperor-mod-manager\cache\

Migrating from Legacy Nexus Manager

If you used the older Nexus Manager app, Emperor can copy over your staged game data on startup as long as the new folder is empty. You can also open Settings → Mod recovery to scan or run it again. Just make sure to deploy each recovered game before deleting the old folder.

6. Troubleshooting & FAQ

“Download with manager” (nxm://) links aren’t opening Emperor

On Windows, use the _x64-setup.exe installer instead of the standalone .exe so the nxm:// handler gets registered. On Linux, use the Arch script, the .deb package, or install the .desktop file included in the release tarball.

How do I update Emperor Mod Manager?

Go to Settings → Check for updates. On Arch it updates through makepkg/pacman, on Debian/Ubuntu through apt, AppImages are replaced in place, and Windows pulls the update straight from GitHub Releases.

My friend shows offline or won’t connect over P2P

Make sure both of you have Emperor open and have opened the Friends page so the P2P node has started. If a connection hangs, hit the refresh button on the Friends page.

Where can I report bugs or request game support?

Open an issue on the GitHub Issue Tracker and include your OS, app version, and which game you’re trying to mod.
