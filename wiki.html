1. Getting Started & Setup

Emperor Mod Manager runs on Linux and Windows 10+. After installing from the Downloads page, connect your mod catalog accounts and detect your installed games.

Connecting your Nexus Mods API Key

  1. Sign in to Nexus Mods and open Nexus API Access .
  2. Create or copy your personal API key.
  3. Open Setup in Emperor Mod Manager and paste your key.
Key storage: Your API key is saved in your operating system keyring whenever available, falling back to the app config directory (restricted to mode 0600 on Linux).

Connecting mod.io (Optional)

  1. Open mod.io Access and generate or copy an API key.
  2. Paste it under Setup → mod.io inside the app.
  3. In Library → Catalog & deploy settings, verify or set the game’s mod.io game ID (many games include a seeded ID automatically).

Detecting & Managing Games

Emperor automatically scans common game libraries:

  • Linux: Steam, Heroic, Lutris, and Bottles.
  • Windows: Steam, Epic Games Launcher, and optional Heroic installs.

Select any detected game in your Library to manage it, inspect its deployment method, and start browsing mods across Nexus, Thunderstore, and mod.io from one unified list.

2. Free-Account Downloads & Download Assist

Nexus Premium accounts enjoy one-click API downloads and automatic batch installs for collections. If you use a free Nexus account, Emperor includes built-in Download Assist:

  1. Open any mod file and choose Download Assist.
  2. Sign in to Nexus Mods inside the assist window the first time and check Stay signed in so future downloads reuse your session.
  3. With autoclick enabled (on by default in Settings), Download Assist waits for the free download button and automatically clicks Mod Manager Download or Slow Download.
  4. You can also click “Download with manager” (nxm://) links in your browser, or use Import mod… on the Mods tab to import any local .zip, .7z, .rar, mod file, or extracted folder.
Session reset: If your Nexus website login expires or you switch accounts, go to Settings → Clear Nexus website session to sign in fresh.

3. Managing Mods & Collections

Emperor makes it easy to organize individual mods into reusable collections, control load order, and install community modpacks.

Installing Collections & Modpacks

  • Nexus Collections: Browse and install Nexus Collections directly. Premium users batch-download automatically; free accounts step through each required mod via Download Assist (use Cancel on the status banner anytime to stop).
  • Thunderstore Modpacks & Profile Codes: Install Thunderstore Modpacks or paste an r2modman / Gale profile code to import a full modlist with soft dependency resolution and pinned versions.

Organizing Load Order & Deploying

  1. Open your managed game’s Mods tab to enable, disable, or reorder staged mods.
  2. Drag and drop mods to adjust load priority—mods lower in the order override earlier files.
  3. Click Deploy to apply your active load order. Emperor uses fast hardlinks whenever the staging folder and game directory share a drive, and falls back to file copies across separate drives.

Shareable Mod Links

Click Copy link on any mod page to copy an emperor://mod/... URL. Sending that link to another Emperor user opens the exact mod directly in their app (supported for Nexus, Thunderstore, and mod.io).

4. Adding Friends & P2P Collection Sharing

Emperor includes a direct peer-to-peer (P2P) Friends system so you and your co-op group can share and sync mod collections without needing a central account server.

Setting Up Your Social Profile

  1. Open Settings → Social.
  2. Enter your Display name and click Save.
  3. Optionally click Choose Picture to upload an avatar (PNG, JPEG, WebP, or GIF; automatically resized and shared with connected friends).

Adding a Friend

  1. Navigate to the Friends page in the sidebar.
  2. To invite someone, click Share Friend Code to copy your P2P join code and send it to them.
  3. To add someone else, click Add Friend, paste their join code, and click Connect. Emperor connects directly over P2P.

Controlling Collection Visibility

Open the Sharing dialog on any collection to choose who can see and sync it:

  • All friends: Visible to every connected P2P friend.
  • Specific friends: Pick individual connected friends (with Select all / clear helpers) who can see and sync that collection.
  • Private: Hidden from all friends.

Syncing a Friend’s Collection

Click a connected friend on the Friends page to browse their shared collections by game. Open a collection to preview its included mods, choose the target managed game, and click Sync or Install to match their modlist.

5. Data Locations & Mod Recovery

Emperor stores configuration, staged mods, and download caches in standard OS locations:

Purpose Linux Windows
Config ~/.config/emperor-mod-manager/ %APPDATA%\emperormodmanager\emperor-mod-manager\
Staged mods & load order ~/.local/share/emperor-mod-manager/ %APPDATA%\emperormodmanager\emperor-mod-manager\
Download cache ~/.cache/emperor-mod-manager/ %LOCALAPPDATA%\emperormodmanager\emperor-mod-manager\cache\

Migrating from Legacy Nexus Manager

If you previously used the legacy Nexus Manager app, Emperor can copy staged game data on startup when the matching folder is empty. You can also open Settings → Mod recovery to scan or rerun recovery, then deploy each recovered game before removing the old data directory.

6. Troubleshooting & FAQ

“Download with manager” (nxm://) links aren’t opening Emperor

On Windows, install using the _x64-setup.exe installer rather than the standalone .exe so the nxm:// protocol is registered. On Linux, use the Arch installer, .deb package, or install the .desktop entry from the release tarball.

How do I update Emperor Mod Manager?

Open Settings → Check for updates. Emperor updates Arch installs via makepkg/pacman, Debian/Ubuntu installs via apt, replaces AppImages in place, and updates Windows installs directly from GitHub Releases.

My friend shows offline or won’t connect over P2P

Ensure both you and your friend have Emperor open and have finished starting the P2P node on the Friends page. Use the refresh button on the Friends page if a connection takes a moment to re-establish.

Where can I report bugs or request game support?

Open an issue on the GitHub Issue Tracker with your OS, app version, and game details.
